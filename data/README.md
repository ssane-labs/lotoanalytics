# Данные тиражей

`draws_6x45.csv` — нормализованный архив (`draw,date,numbers`). Его пишет
`scripts/build_data.py` при успешном разборе сайта и читает GitHub Actions,
когда сеть или вёрстка Столото подводят.

Положить архив вручную:

    python scripts/build_data.py --csv путь/к/скачанному.csv

Парсер CSV распознаёт и `draw,date,n1..n6`, и русские заголовки
`Тираж,Дата,Числа` с числами одной строкой.
