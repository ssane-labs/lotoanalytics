# История тиражей

Накопленный архив Столото, по два файла на игру:

- `draws_<игра>.csv` — `draw,date,numbers`. Поля билета разделены « | »:
  `3 7 12 18 | 2 9 14 20` в «4 из 20».
- `results_<игра>.jsonl` — итоги тиража: ставок (`cols`, у части игр не
  публикуется), суперприз, цена билета, победители (`n`) и выплаты (`amt`) по
  категориям. Поле `t` есть, только если набор категорий отличается от
  нынешних правил игры.
- `upcoming_<игра>.json` — ближайший тираж и суперприз, который на кону.

Архив только растёт. Докачать недостающее:

    python scripts/fetch_history.py
