# Лотерейный аналитик — Telegram Mini App

Telegram-бот с Mini App, который считает **не то, что выпадет**, а **сколько
человек поставили ту же комбинацию, что и вы**.

## В чём идея

Вероятность выиграть у любой комбинации одинакова — 1 к 8 145 060 для
«6 из 45». Никакая модель этого не меняет, и приложение этого не обещает.

Но джекпот пари-мьютюэльный: он делится между всеми, кто угадал. Игроки
выбирают числа крайне неравномерно — дни рождения (1–31), «счастливую» семёрку,
ровные прогрессии, линии и столбцы на бланке. Из-за этого на одни комбинации
приходятся сотни ставок, а на другие — ни одной.

Отсюда единственный честный эдж в лотерее: **шанс выиграть не растёт, растёт
ожидаемая выплата при выигрыше**. Цифры из реального расчёта:

| Комбинация | Ожидаемых совладельцев джекпота | Ваша доля |
|---|---:|---:|
| `1 2 3 4 5 6` | 264 | 0,4 % |
| `5 10 15 20 25 30` (прогрессия) | 180 | 0,6 % |
| `3 7 11 12 21 28` (дни рождения) | 0,61 | 75 % |
| `13 36 38 39 43 44` (подбор) | < 0,01 | 100 % |

При джекпоте 500 млн ₽ разница между первой и последней строкой — сотни
миллионов рублей ожидаемой выплаты. При одинаковом шансе выиграть.

## Чего здесь нет

Предсказаний. Во вкладке «Проверка» приложение показывает результат
собственного бэктеста: семь стратегий (включая марковскую модель и, если
установлен scikit-learn, градиентный бустинг) обучаются на истории и
проверяются на тиражах, которых не видели.

```
Стратегия                             совпадений   разница   p-value
Марковская модель переходов               0.8546   +0.0546    0.0120
Давно не выпадали                         0.8423   +0.0423    0.0517
Горячие за 50 тиражей                     0.8308   +0.0308    0.1570
Холодные числа                            0.8231   +0.0231    0.2885
Горячие числа (вся история)               0.8154   +0.0154    0.4792
Повтор прошлого тиража                    0.8123   +0.0123    0.5713
Случайный выбор (контроль)                0.8031   +0.0031    0.8875
```

Предел случайного угадывания — 0,8 совпадения на тираж. Ни одна стратегия его
не обходит. Это не позиция, а воспроизводимый результат: `python
scripts/verify_randomness.py --csv data/draws_6x45.csv`.

## Запуск

Нужны только бесплатные сервисы. Домен покупать не надо: `логин.github.io` —
уже валидный HTTPS-домен, Telegram его принимает.

### 1. Токен бота

Токен, который вы отправляли в переписке, **отзовите**: BotFather →
`/mybots` → бот → API Token → **Revoke current token**. Новый нигде не
записывайте в файлы — он живёт только в секретах Cloudflare.

### 2. GitHub Pages

```bash
git remote add origin https://github.com/ssane-labs/lotoanalytics.git
git push -u origin main
```

Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка
`/docs`. Через минуту Mini App живёт на
`https://ssane-labs.github.io/lotoanalytics/`.

### 3. Реальные данные

В репозитории лежат **синтетические** данные — приложение показывает про это
жёлтую плашку. Заменить:

```bash
# Вариант А: скачать архив кнопкой на https://www.stoloto.ru/6x45/archive
python scripts/build_data.py --csv ~/Downloads/archive.csv

# Вариант Б: попробовать разобрать сайт автоматически
python scripts/build_data.py --fetch
```

Парсер сайта написан защитно и при любом сомнении падает с внятной ошибкой,
а не подсовывает мусор. Столото не даёт публичного API и меняет вёрстку, так
что вариант А — надёжный, а Actions при неудаче сети автоматически
откатывается на закоммиченный CSV.

### 4. Бот

Самый быстрый путь — вообще без кода: BotFather → `/mybots` → бот →
Bot Settings → Menu Button → указать адрес Pages. Кнопка в боте начнёт
открывать Mini App.

Для команд `/start`, `/help`, `/honest` разверните Worker (бесплатный тариф):

```bash
cd bot
# впишите свой адрес Pages в MINIAPP_URL внутри wrangler.toml
npx wrangler deploy
npx wrangler secret put BOT_TOKEN        # новый токен от BotFather
npx wrangler secret put WEBHOOK_SECRET   # любая длинная случайная строка
```

Привязать вебхук и кнопку Mini App:

```bash
export BOT_TOKEN="токен от BotFather"
python bot/setup_telegram.py status                 # что настроено сейчас
python bot/setup_telegram.py commands               # список команд
python bot/setup_telegram.py menu                   # кнопка -> Mini App
python bot/setup_telegram.py webhook https://ваш-воркер.workers.dev СЕКРЕТ
```

`menu` сначала проверяет, что адрес реально отвечает, и отказывается ставить
кнопку на неработающий Pages — иначе бот выглядел бы сломанным.

### Проверить без деплоя

Пока облака нет, бот можно поднять прямо на своей машине — ни вебхука, ни
HTTPS, ни домена не нужно:

```bash
export BOT_TOKEN="токен от BotFather"
python bot/local_bot.py
```

Работает, пока открыто окно. Для продакшна нужен воркер.

### 5. Автообновление

`.github/workflows/update-data.yml` раз в сутки тянет свежие тиражи,
пересчитывает статистику и коммитит в `docs/data/`. Коммит = публикация,
отдельный деплой не нужен.

## Проверьте перед публикацией

Два места, где стоят значения-заглушки, и от них зависят все денежные цифры:

1. **Призовые уровни** в `model_params.json` → `games.6x45.prizes_rub`.
   Сверьте с официальными правилами. Сейчас: 2 → 100 ₽, 3 → 300 ₽, 4 → 1500 ₽,
   5 → 30 000 ₽, 6 → пари-мьютюэль.
2. **Число игроков в тираже** (`typical_players_per_draw`, сейчас 1 500 000).
   От него зависит ожидаемое количество совладельцев джекпота.

**Веса модели популярности** — оценки из опубликованных исследований выбора
чисел игроками, а не измерения на российских данных. Это честно написано и в
коде, и в интерфейсе. Направление эффектов надёжное (дни рождения и узоры
переоценены — это воспроизводится во всех изученных лотереях), точные
множители — приблизительные.

## Как устроено

Бэкенда нет вообще. GitHub Actions раз в сутки собирает статические JSON,
GitHub Pages их раздаёт, браузер считает всё на клиенте. Сервер не видит ни
одной пользовательской комбинации — их просто негде утечь.

```
model_params.json          единственный источник правды для модели
scripts/lotto/
  popularity.py            модель популярности комбинаций
  ev.py                    ожидаемая выплата с делением джекпота (Пуассон)
  generator.py             подбор непопулярных комбинаций
  stats.py                 статистика тиражей + хи-квадрат
  sources.py               Столото / CSV / синтетика
scripts/build_data.py      сборка docs/data/*.json
scripts/verify_randomness.py   бэктест предсказуемости
docs/                      Mini App (GitHub Pages)
  model.js                 порт popularity.py и ev.py на JS
  app.js, index.html, styles.css
bot/worker.js              Telegram-бот на Cloudflare Workers
tests/                     тесты ядра и паритета Python/JS
```

Модель популярности живёт в двух реализациях — Python для сборки, JS для
браузера. Расхождение означало бы, что пользователь видит не то, что мы
считали, поэтому `tests/parity.test.mjs` сверяет их по 400 эталонным векторам
с допуском 1e-9.

### Тесты

```bash
python tests/test_core.py     # 25 тестов математического ядра
node tests/parity.test.mjs    # Python и JS считают одинаково
```

Отдельно проверяется, что **ожидаемая выплата отрицательна** — если этот тест
когда-нибудь упадёт, значит в расчёт закралась ошибка, а не найден грааль.

## Монетизация

Что можно продавать, ничего не обещая ложно:

- **Подписка на подбор.** Бесплатно — одна комбинация в день; по подписке —
  пакеты билетов с непересекающимися числами, сохранение и проверка билетов.
- **Партнёрская программа** легальных операторов.
- **Честность как позиционирование.** Рынок забит «предсказателями». Продукт,
  который открыто показывает, что предсказание невозможно, и объясняет
  единственный работающий приём, — это то, чем можно делиться и о чём пишут.

Чего делать нельзя ни при каких обстоятельствах: обещать предсказание
результатов, повышение шанса выигрыша или гарантированный выигрыш. Это
уголовная статья (мошенничество), а не маркетинговый риск.

## Ответственная игра

Ожидаемая выплата билета ниже его цены — всегда, при любой комбинации.
Приложение показывает это прямым текстом, включая расчёт джекпота
безубыточности (около 613 млн ₽ при текущих параметрах). Лотерея — это
развлечение с отрицательным матожиданием, а не способ заработка.
