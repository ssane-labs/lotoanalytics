# Лотерейный аналитик — Telegram Mini App

Telegram-бот с Mini App, который оценивает **не то, что выпадет**, а
**сколько человек поставили ту же комбинацию, что и вы**. Игры: «6 из 45»,
«7 из 49», «4 из 20», «5 из 36» и «Большое Спортлото» (5 из 50 + 2 из 10).

## В чём идея

Вероятность выиграть у любой комбинации одинакова — 1 к 8 145 060 для
«6 из 45». Никакая модель этого не меняет, и приложение этого не обещает.

Но суперприз пари-мьютюэльный: он делится между всеми, кто угадал. Игроки
выбирают числа неравномерно, поэтому одни комбинации ставят чаще других.
Приложение подбирает те, что ставят реже, — шанс выиграть тот же, выплата
при выигрыше делится с меньшим числом людей.

## Откуда данные

Архив тиражей Столото (`scripts/lotto/stoloto_api.py`). Кроме чисел он отдаёт
итоги каждого тиража: сколько было ставок и сколько из них выиграло в каждой
категории. История лежит в `data/` (`draws_*.csv` — числа, `results_*.jsonl` —
итоги), каждый день дописывается GitHub Actions.

| Игра | Тиражей в архиве |
|---|---:|
| «6 из 45» | 18 875, с 2008 года |
| «7 из 49» | 24 140 |
| «4 из 20» | 15 395 |
| «5 из 36» | последние 20 000 (тираж каждые 15 минут) |
| «Большое Спортлото» | 3 312 |

Цена билета, суперприз, средние выплаты по категориям и число ставок в
тираже тоже берутся из итогов, а не из головы.

## Модель популярности

Обучена на итогах тиражей (`scripts/calibrate_popularity.py`). Если выпали
числа, которые люди любят ставить, победителей больше расчётного; если
нелюбимые — меньше. По тысячам тиражей это восстанавливает, как игроки
выбирают числа:

1. **Веса отдельных чисел.** Точная формула совпадений через элементарные
   симметрические многочлены, максимум правдоподобия по числу победителей.
2. **Структура набора** — соседние числа, серии, баланс чётных, сумма, узкий
   диапазон, узоры бланка. Выборка по значимости, веса чисел учатся заново
   вместе со структурой.

Каждый этап проверяется на последних 20 % тиражей, которых модель не видела.
Структура принимается, только если она улучшает прогноз на них: в «5 из 36» и
«Большом Спортлото» не улучшает, там модель держится на весах чисел.

Что показали данные «6 из 45» (8 000 последних тиражей):

- чаще всего ставят 7, 13, 11, 8, 21; реже всего — 38, 40, 1, 36, 45;
- комбинации без соседних чисел ставят вдвое охотнее, серию из трёх подряд — в 13 раз реже,
  все числа в узком диапазоне — в 12 раз реже;
- литературные множители, которые стояли в модели раньше («баланс чётных ×1,3»,
  «прогрессия ×25»), на российских данных не подтвердились: с ними прогноз
  хуже, чем вовсе без структуры.

Переобучение — вручную, раз в несколько месяцев (нужны `torch` и `scipy`):

```
python scripts/calibrate_popularity.py
python tests/make_vectors.py
```

## Нейросеть

Режим «Нейросеть» — перцептрон 15→32→16→1 по частотам чисел в окнах от 5 до
1000 тиражей, разрывам и истории. Учится каждый день на всей истории каждого
поля. На отложенных тиражах она угадывает столько же, сколько случайный выбор
(«6 из 45»: 0,79 числа против 0,80) — тиражи независимы. Из её вариантов
берётся самый редкий у других игроков.

## Сколько это стоит

Подписки нет. Единица работы — **прокрутка**: одна подобранная комбинация.
Разбор своей комбинации стоит две.

| Откуда прокрутки | Сколько |
|---|---|
| Бесплатно | 1 в день |
| За просмотр рекламы | до 5 в неделю |
| Пакет | 1 — 30 ⭐, 5 — 125 ⭐ (25 за штуку), 10 — 200 ⭐ (20 за штуку) |
| За приглашённого друга | +3 обоим, до 10 друзей |

Купленные прокрутки не сгорают. Баланс и списание живут на сервере
(`bot/worker.js`), а не в браузере: страницу можно переписать в консоли,
поэтому решение «хватило или нет» принимает тот, кто хранит.

Прокрутка за рекламу начисляется двумя путями — приложение сообщает о
досмотре, и Adsgram зовёт Reward URL; второй вызов в пределах 90 секунд
считается тем же просмотром. Команда `/ads` (только админам) показывает
журнал последних рекламных событий.
